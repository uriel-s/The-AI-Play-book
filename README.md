# The Engineer's AI Playbook 🚀

**By Uriel Sachs** — Practical guide for R&D engineers on Context Engineering, Prompting Techniques, Custom Skills, Agentic Workflows, and Guardrails.

✨ **[Read the full interactive guide (Live HTML)](https://uriel-s.github.io/The-AI-Play-book/The_Engineers_AI_Playbook.html)**

מתוך הדרכות מעשיות על AI וכלי AI שהעברתי למהנדסים:
* **ניהול הקשר (Context Engineering):** חלון ההקשר, מניעת Context Poisoning / Pollution, ניהול סשנים וזיכרון (`CLAUDE.md`).
* **טכניקות פרומפטינג הנדסיות:** שלד הפרומפט, Few-Shot, Ask-Before-Answer, פיצול שלבים וביקורת עצמית.
* **Custom Skills:** בניית מיומנויות חוזרות (תבניות תוכן ו-Skills דטרמיניסטיים מגובי-סקריפט).
* **סוכנים (Agents & Subagents):** עבודה עם סוכנים רדודים ועמוקים, האצלה לתת-סוכנים ו-Guardrails.
* **אימות ובקרה:** זיהוי הזיות, הנחות שקטות וחנופה (Sycophancy), ואימות צולב.
